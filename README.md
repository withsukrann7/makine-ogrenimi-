# 🧠 Makine Öğrenmesi Notlarım

Makine öğrenmesi öğrenirken yaptığım küçük denemeleri, öğrendiklerimi ve örnek projeleri bir araya getirdiğim kişisel çalışma alanım. 🚀

Bu depo, öğrenme sürecimi adım adım belgelemek ve çalışmalarımı paylaşmak için oluşturuldu. Her çalışma, konuları uygulayarak daha iyi anlamama yardımcı oluyor. 📚

## 🎯 Amaç

- Makine öğrenmesi konularını uygulamalı öğrenmek
- Küçük deneyleri ve projeleri tek yerde toplamak
